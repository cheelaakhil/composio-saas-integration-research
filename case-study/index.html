CONTRADICTION RULE

Public Docs ≠ Self-Serve Access

Flags records where public developer endpoints are tagged "Self-serve" if vendor requires enterprise contracts (e.g. DealCloud, Amazon SP-API, Google Ads, Meta Ads, Paygent Connect).

PROVENANCE RULE

MCP First-Party Verification

Validates whether an MCP repository is authored directly by the vendor organization vs community contributors (e.g. Slack vs Airtable community wrapper).

EVIDENCE RULE

Multi-Source Quoting

Rejects single-source claims; mandates at least 2 distinct official documentation URLs with exact verbatim quote snippets.

EVIDENCE INTEGRITY

Research Methodology & Rules

01

Hierarchical Source Priority

Official developer portals (developer.domain.com, docs.domain.com) take absolute precedence. Secondary blog posts and forum comments are rejected.

02

Verbatim Evidence Snippets

Every claim (e.g. "Personal Access Tokens available in account settings") must link directly to an active URL and include verbatim snippet text.

03

Immutable First-Pass Snapshot

Raw first-pass outputs are preserved separately from the corrected dataset, allowing the verification process and accuracy improvement to be audited.

04

Structured Stratified Verification

A balanced 20-app sample across 4 difficulty tiers was manually vetted across 8 discrete claims (160 claims total) to calculate audited accuracy metrics.
